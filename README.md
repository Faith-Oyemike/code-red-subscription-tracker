# Code Red Subscription Tracker

## Overview

Code Red is a backend-focused web application that helps users identify, manage, and monitor their subscriptions.

The goal is to help users avoid wasting money on subscriptions they no longer use by providing intelligent alerts before payments are taken.

---

## Problem

Many people subscribe to services and forget about them.

Over time they continue paying for:

- Streaming services
- Gym memberships
- Cloud storage
- Software subscriptions

even when they are no longer using them.

---

## Solution

Code Red helps users:

- Track subscriptions
- Monitor renewal dates
- Detect potentially unused services
- Receive warning alerts before payments are taken
